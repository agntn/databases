Point the package at a database and start reading. You need Node.js 26 or newer.

```bash
pnpm add @agntn/databases
```

## What does a table contain?

The examples use Chinook, a sample music store database. The following command runs from `/var/tmp/chinook`, where `chinook.db` lives.

```bash
databases schema chinook.db Track
```

```text
In /var/tmp/chinook/chinook.db (sqlite):
Track (table), 9 columns:
  TrackId  INTEGER  not null  primary key 1
  Name  NVARCHAR(200)  not null
  AlbumId  INTEGER  null
  MediaTypeId  INTEGER  not null
  GenreId  INTEGER  null
  Composer  NVARCHAR(220)  null
  Milliseconds  INTEGER  not null
  Bytes  INTEGER  null
  UnitPrice  NUMERIC(10,2)  not null
3 indexes:
  IFK_TrackMediaTypeId (MediaTypeId)
  IFK_TrackGenreId (GenreId)
  IFK_TrackAlbumId (AlbumId)
3 foreign keys:
  (MediaTypeId) -> MediaType (MediaTypeId)
  (GenreId) -> Genre (GenreId)
  (AlbumId) -> Album (AlbumId)
```

A schema beats guessing column names. Is it `Name` or `TrackName`? Now you know.

## Want a look at the records?

Sample a table without writing SQL. Chinook has room for both Jazz and Metal.

```bash
databases sample chinook.db Genre -n 3
```

```text
/var/tmp/chinook/chinook.db (sqlite): 3 rows, more not read (limit 3)
columns: ["GenreId","Name"]
types: ["integer","nvarchar(120)"]
[1,"Rock"]
[2,"Jazz"]
[3,"Metal"]
More rows exist. Narrow the query, aggregate it, or raise limit (up to 1000).
```

For your first query, send SQL through standard input.

```bash
echo 'SELECT count(*) FROM Track' | databases query chinook.db -
```
