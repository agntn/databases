Give your agent a connection name and a specific question. It can inspect the schema before it writes any SQL. Which tool goes first? `databases_providers`, so it learns the names.

## Which tools can it call?

- `databases_providers` lists engines, redacted connections and write availability without connecting.
- `databases_schema_get` lists tables and views, or describes one table.
- `databases_table_sample` reads initial rows without SQL, in undefined order.
- `databases_query` runs one read-only statement.
- `databases_explain` returns a plan without running the statement.
- `databases_execute` runs one statement that may write.
- `databases_migrations_status` shows which migration files a database has run and which wait.
- `databases_migrations_create` writes the next numbered `.sql` file and touches no database.
- `databases_migrations_apply` runs the pending files, each in its own transaction.

Schema details include column types, nullability, defaults, primary keys, indexes and foreign keys. Explain uses `EXPLAIN` for Postgres and `EXPLAIN QUERY PLAN` for SQLite and D1. It refuses writes too.

## How do you install the tools?

For Pi:

```bash
pi install npm:@agntn/databases
```

For OMP:

```bash
omp install @agntn/databases
```

The native Pi extension does not ask for confirmation before `databases_execute`. Experimental writes need no environment switch. OMP retains host write approval metadata for this destructive tool.

## What about MCP?

Start the server with `databases mcp`, or configure a client:

```json
{
  "mcpServers": {
    "databases": {
      "command": "npx",
      "args": ["-y", "@agntn/databases", "mcp"],
      "env": {
        "DATABASES_SHOP_URL": "postgres://reader:secret@localhost:5432/shop"
      }
    }
  }
}
```

That password is illustrative, not a secret to reuse. MCP writes need no environment switch, though external client policies remain independent.

## Using the AI SDK?

Install the `ai` peer, then pass the exported tools to `generateText`.

```ts [agent.ts]
import { generateText } from "ai"
import { databasesAiTools } from "@agntn/databases/ai"

const result = await generateText({
  model,
  prompt: "Inspect shop and summarize the orders table.",
  tools: databasesAiTools,
})
```

Supply your configured `model` in that example.

## How should you prompt an agent?

Name the connection, the question and any boundaries. Ask it to use parameters for values instead of assembling SQL. Tell it whether a sample or an aggregate answers the question.

A request to delete the music store deserves scrutiny. Write access is not a substitute for an explicit instruction. See [connections](/guide/connections) and [read only](/guide/read-only).
