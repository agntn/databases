## What changes between engines?

[SQLite](/providers/sqlite) reads a local file in a child process. [Postgres](/providers/postgres) connects with a URL and uses read-only transactions. [Cloudflare D1](/providers/d1) checks SQL against a local schema copy before sending it.

Does that make them the same? No. A music store on disk is not a remote D1 database. The same tool names do not make their precision or permissions identical.

## Where should you start?

Use [connections](/guide/connections) to choose a reference or name. Read [read only](/guide/read-only) for the full refusal rules. The [CLI](/guide/cli) and [library](/guide/library) guides show how to call the tools.
