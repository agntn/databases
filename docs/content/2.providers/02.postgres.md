A Postgres URL is enough to identify your database. Neon and Supabase use the same `postgres://` reference form.

::provider-roster{engine="postgres"}
::

## What happens on a read?

Each call uses a short connection. The session sets `default_transaction_read_only`, and reads run in a `READ ONLY` transaction. A `statement_timeout` set for that transaction stops a statement after 30 seconds. The extended protocol refuses a second command in one string.

A transaction is not a substitute for permissions. Functions with side effects, such as `pg_terminate_backend`, depend on role privileges. Use a role with only SELECT permissions. Want the agent to see two tables and not the rest? Grant SELECT on those two.

## How are names and numbers handled?

Unquoted names fold to lower case for schema and sample calls. Postgres `numeric` and `bigint` values come back as exact strings. That matters when a price or identifier must survive intact.

```bash
databases schema shop orders
```
